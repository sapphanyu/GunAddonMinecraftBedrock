# Handheld 2D Extruded Item Model

We decided to render the Glock-18 using a high-fidelity 2D pixel art texture with native Minecraft 3D volumetric extrusion (`handheld` rendering) rather than custom Blockbench 3D polygon geometry (`.geo.json`). This preserves the authentic vanilla Minecraft aesthetic, prevents visual clipping during combat, and keeps the resource pack lightweight while ensuring seamless rendering across all viewpoints.
